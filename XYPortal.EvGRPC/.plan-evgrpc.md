## Phase 1 — gRPC 项目骨架 + proto 同步

> Outcome: a buildable `XYPortal.EvGRPC.gRPC` project whose
> compile output contains C# classes for every service in
> `proto/evgrpc/`, and a SHA-256 manifest that CI can later verify.

- [ ] **1.1** Create the project skeleton. `[auto]`
       **Where**: `XYPortal.EvGRPC/src/XYPortal.EvGRPC.gRPC/`
       **Action**: `dotnet new classlib -n XYPortal.EvGRPC.gRPC
       -f net10.0` from inside the module directory; then edit
       the `.csproj` to add `<PackageReference>`s for
       `Grpc.Net.Client`, `Google.Protobuf`,
       `Grpc.Tools` (all current stable), and the standard
       ABP module contract (`Volo.Abp.Core`).
       **Artifact**: `XYPortal.EvGRPC/src/XYPortal.EvGRPC.gRPC/XYPortal.EvGRPC.gRPC.csproj`
       plus an empty `EvGrpc/` namespace folder.
       **Verify**: `dotnet build XYPortal.EvGRPC.slnx` exits 0
       with the new project included.
       **Stop on**: `dotnet build` fails on .NET 10 SDK ↔
       `Grpc.Tools` mismatch (escalate, see Risks R-3).

- [ ] **1.2** Add `proto/evgrpc/*.proto` to the project. `[auto]`
       **Where**:
       `XYPortal.EvGRPC/src/XYPortal.EvGRPC.gRPC/proto/evgrpc/`
       **Action**: `mkdir -p` the folder; `rsync -a --delete
       /data/Repositories/evGRpc/proto/evgrpc/ ./proto/evgrpc/`
       (first sync against upstream HEAD `2697b79...`).
       Edit the `.csproj` so `<Protobuf Include="proto/**/*.proto"
       GrpcServices="Client" />` lists every file.
       **Artifact**: 7 `.proto` files under the project +
       `<Protobuf>` entries in the csproj.
       **Verify**: `dotnet build` regenerates `obj/Debug/.../Evgrpc/*.cs`
       containing `Vehicle`, `Charging`, etc.

- [ ] **1.3** Commit the upstream SHA-256 manifest. `[auto]`
       **Where**:
       `XYPortal.EvGRPC/src/XYPortal.EvGRPC.gRPC/proto/evgrpc/.upstream.sha256`
       **Action**: `sha256sum *.proto > .upstream.sha256` (the
       7-line manifest already captured in the brainstorm).
       **Artifact**: `.upstream.sha256` next to the protos.
       **Verify**: `cd proto/evgrpc && sha256sum -c .upstream.sha256`
       prints "OK" for every line.
       **Stop on**: SHA mismatch against the values in the
       brainstorm → rsync silently dropped/added files; re-sync.

- [ ] **1.4** Drop a stub `EvGrpcClient`. `[auto]`
       **Where**:
       `XYPortal.EvGRPC/src/XYPortal.EvGRPC.gRPC/EvGrpc/EvGrpcClient.cs`
       **Action**: declare a class
       `public sealed class EvGrpcClient : IDisposable` that
       internally builds a `GrpcChannel` from constructor-injected
       options (`Url`, `AccessToken`). Expose one throwaway method
       `Task<PingResult> PingAsync()` that calls an obvious
       no-op RPC (or a `Metadata`-echoing Unary call) so we have
       a wire-level smoke test before any mapping.
       **Artifact**: `EvGrpcClient.cs` + `EvGrpcOptions.cs`.
       **Verify**: `dotnet build` clean.

- [ ] **1.5** Phase 1 commit. `[user]`
       **Where**: working tree of `feature/evgrpc`.
       **Action**: commit message
       `feat(evgrpc): scaffold gRPC project, sync .proto from evGRpc@2697b79`.
       **Stop on**: build error or rsync hash mismatch.

## Risks

- **R-1 proto drift upstream** — even with manual rsync + CI
  hash check, a contributor could `cp` new protos without
  bumping `.upstream.sha256`. **Abort when**: CI
  `proto-drift-check` is not present in CI after Phase 4.5.
- **R-2 JWT lifecycle** — bearer token may expire mid-session;
  v1 has no refresh flow. **Abort when**: a hand-test of
  Phase 3.5 fails after the token is older than evGRpc's
  expected lifetime; surface as a UserFriendlyException.
- **R-3 `Grpc.Tools` ↔ .NET 10 SDK** — Phase 1.1 might fail
  to compile if the package version doesn't match the SDK.
  **Abort when**: `dotnet build` cannot resolve
  `Grpc.Tools`; pin a known-good version or wait for an
  upstream update.
- **R-4 `license_plate` UNIQUE in evGRpc** — duplicate creation
  produces `ALREADY_EXISTS`. **Abort when**: the exception
  path in Phase 3.2 does not surface the friendly message
  to the user; add a per-violation translator.
